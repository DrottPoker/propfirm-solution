# Handelsterminal

Webbgränssnittet för traders i handelsplattformen (Produkt 1): graf, orderformulär, positioner och historik.

Byggs i fas 3. Kör lokalt med `pnpm dev` på http://localhost:3001.

Får inte importera kod från `prop/`. Se [ADR 0001](../../docs/adr/0001-monorepo-med-produktgranser.md).
